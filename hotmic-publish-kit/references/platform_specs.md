# 各平台发布规范

本文档记录视频号和抖音的字数限制、Tag 规范及发布注意事项。
`generate_publish_pack.py` 在生成发布包时会参考本文档的限制进行校验。

---

## 视频号

### 字数限制

| 字段 | 限制 | 建议 |
|------|------|------|
| 视频标题 | 最多 30 字 | 20-28 字，留余量 |
| 简介/文案 | 最多 1000 字 | 100-300 字，简洁有力 |
| 单个 Tag | 无硬性限制 | 2-8 字为佳 |
| Tag 数量 | 无硬性限制 | 10 个（覆盖热点词+品类词+栏目词）|

### Tag 分类建议

```
热点词（2-3个）: 当前热门话题词，如 #健康科普 #医生说
品类词（3-4个）: 内容所属品类，如 #中老年健康 #老年人用药
栏目词（2-3个）: 账号自有栏目标签，如 #[账号名]说健康
```

### 简介格式

```
[1-2句核心内容提炼]
[1句观看提示/转发引导]
#Tag1 #Tag2 #Tag3 ...
```

### 封面规范

- 主标题（大字）：6-10 字，核心结论或冲突点
- 副标题（小字）：10-20 字，补充说明
- 设计建议：白底黑字或深色底浅色字，字体清晰易读

### 首评规范

- 发布后立即评论，置顶
- 内容：补充信息 / 汇总问题 / 理性讨论引导
- 长度：100-300 字
- 格式：分点列出，便于阅读

### 发布时间

- 推荐时段：晚上 8:00-10:00（家庭时间，高传播概率）
- 周末下午 3:00-5:00 效果也不错
- 避免：工作日早上（用户无时间看完）

## 抖音

### 字数限制

| 字段 | 限制 | 建议 |
|------|------|------|
| 视频标题 | 最多 55 字 | 20-35 字，包含关键词 |
| 简介/文案 | 最多 500 字 | 80-200 字 |
| 单个 Tag | 无硬性限制 | 2-8 字 |
| Tag 数量 | 建议 ≤20 个 | 10 个精准 Tag |

### Tag 分类建议

```
热点词（3-4个）: 当前算法热推词，如 #健康科普 #医学知识
品类词（3-4个）: 垂直领域词，如 #中老年健康 #健康养生
账号词（2-3个）: 账号标签词，如 #医生科普
```

### 简介格式

```
[1句核心结论]
本视频：①[要点1] ②[要点2] ③[要点3]
#Tag1 #Tag2 ...
```

### 封面规范

- 主标题（大字）：6-8 字，冲击力强
- 副标题（小字）：8-15 字
- 设计建议：视觉冲击感强，高对比度，文字放大

### 首评规范

- 发布后立即评论
- 内容：引发讨论 / 补充一个意外信息点 / 站队邀请
- 长度：50-150 字
- 格式：简短有力，1-2 句

### 发布时间

- 推荐时段：
  - 早上 7:00-9:00（通勤刷手机）
  - 中午 12:00-13:00（午休）
  - 晚上 7:00-9:00（主力时段）
- 避免凌晨发布（冷启动差）

## 飞书归档规范

### 文档命名

格式：`MMDD 标题关键词`

示例：
- `0323 外泌体风险提示`
- `0318 老年人饮水量误区`
- `0415 体检报告必看5指标`

### 归档内容

飞书文档必须包含完整 9 件套：
1. 视频号版脚本
2. 抖音版脚本
3. 合规自检结果
4. 素材来源（含链接）
5. 平台标题建议
6. 视频封面标题
7. 简介
8. Tags
9. 首评话术
