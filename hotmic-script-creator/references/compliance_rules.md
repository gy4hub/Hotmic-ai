# 合规红线完整清单

本文档定义了 `hotmic-script-creator` 的6条合规红线。
命中任何一条 = 打回重写，不允许部分通过。

---

## 合规自检执行规范

1. 自检必须逐条执行，不允许"整体看了没问题"的笼统判断
2. 每条必须输出明确的 ✅（通过）或 ❌（未通过）+ 说明
3. 发现问题时，必须给出具体的修改建议，不允许只标记"有问题"
4. 自检完成后输出汇总：`X条通过，Y条不通过`
5. 有任何一条不通过，必须修改后重新提交自检

---

## 六条合规红线

### C01 — 诊断性表述

**定义**：对用户/患者的身体状况做出诊断性判断。

**触发关键词/句式**：
- "你可能是/你这是..."（后接病名或症状解释）
- "根据你说的情况，判断你..."
- "这说明你的[器官/系统]..."（后接病理性判断）
- "你的症状符合..."
- "看起来你有..."（后接医学症状）

**不触发**（安全表述）：
- "有这类情况的人，建议去医院检查..."
- "如果出现A、B、C症状，可能与...有关，需要就医"
- "医生会根据具体情况来判断..."

**修改示例**：
```
❌ 你描述的这些症状，很可能是外泌体治疗引起的过敏反应。
✅ 如果出现这类症状，需要及时就医，让医生评估是否与治疗有关。
```

---

### C02 — 承诺疗效

**定义**：对某种治疗、方法、产品的效果做出确定性承诺。

**触发关键词**：
- 一定能/保证/肯定会/绝对/必然（后接正面效果）
- 只要...就一定...（后接疗效承诺）
- 100%有效/完全治愈/根治/彻底解决
- 立竿见影/马上见效/几天内必然

**不触发**（安全表述）：
- "研究显示，部分患者在...方面有所改善"
- "临床数据表明，有效率约为X%"（须有来源）
- "对部分人群有帮助，但需要在医生指导下使用"

**修改示例**：
```
❌ 坚持这个方法，你的血压一定能降下来。
✅ 这个方法对部分高血压患者有辅助作用，但具体效果因人而异，建议配合医嘱使用。
```

---

### C03 — 推荐具体品牌

**定义**：在脚本正文中出现具体品牌名、商品名、产品型号。

**触发**：
- 品牌名（药品品牌、保健品品牌、医疗器械品牌等）
- 具体产品名（xx牌xx片、某某胶囊等）
- 可识别的产品型号

**例外（不触发）**：
- 以"教育性内容"方式说明某类产品的选择标准（不点名具体品牌）
- 用"某品牌"代替实际品牌名
- 在来源标注中提及（不在正文脚本中）

**修改示例**：
```
❌ 我推荐大家用XX牌的外泌体产品，效果不错。
✅ 选择外泌体相关产品时，要注意查看是否有正规批文，成分是否经过第三方检测。
```

---

### C04 — 声称未持有的专业身份

**定义**：在脚本中使用创作者实际上没有的专业资质或身份。

**触发**：
- 声称拥有未持有的医师执照
- 使用虚假的职称（如未持有"主任医师"资质却自称）
- 声称在从未工作过的机构任职
- 使用误导性头衔（"专家""权威"等无认证背书的称谓）

**使用规则**：
- 创作者的真实资质必须在 `persona.json` 中明确记录
- 每次创作前校验脚本中出现的身份描述是否与persona一致
- 若persona中未记录某项资质，不得在脚本中声称

**修改示例**：
```
❌ 作为一名神经外科主任医师，我来告诉你...（创作者实际是内科医师）
✅ 作为一名内科医师，我从临床角度来看这个问题...
```

---

### C05 — 未验证数据

**定义**：脚本正文中出现具体数字、统计数据、研究结论，但没有权威来源URL支撑。

**触发**：
- "研究显示，X%的人..."（无来源）
- "根据最新数据，中国有X万名患者..."（无来源）
- "临床试验证明..."（无来源）
- 任何具体数字（百分比、人数、时间、金额等）+ 无来源标注

**不触发**（安全表述）：
- 模糊表述："很多人""部分患者""有研究认为"
- 已在素材来源清单中标注URL的数据
- 创作者亲身经历的描述（"我见过的患者里..."）

**修改示例**：
```
❌ 有研究显示，外泌体治疗对80%的患者有效。
✅ 目前外泌体在临床研究阶段，部分研究显示有一定效果，但大规模临床数据尚不充分。（[来源URL]）
```

---

### C06 — 歪曲政策原文

**定义**：对政策文件、法规、官方指南的不准确引用或断章取义。

**触发**：
- 引用政策文件时，内容与原文有实质性出入
- 断章取义（摘取部分内容，忽略限定条件）
- 将"讨论中的政策"表述为"已实施的政策"
- 将地方政策表述为全国政策（或反之）
- 将过期政策作为现行政策引用

**操作规则**：
- 凡引用政策，必须附原文链接或明确文件名称
- 如无法确认政策原文，使用模糊表述："据报道""有政策显示"
- 政策类内容是高风险区域，审查时应重点检查

**修改示例**：
```
❌ 国家规定，外泌体产品必须经过临床试验才能上市。
✅ 根据国家药监局发布的《[具体文件名]》（[链接]），相关产品的审批要求是...
```
