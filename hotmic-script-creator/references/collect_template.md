# 收藏款脚本结构模板

收藏款以信息密度为核心，目标是让观众觉得"这个太有用了，先收藏"。

---

## 结构总览

```
[第一层] 价值承诺（明确告诉观众这篇能给他们什么）
[第二层] 核心清单/步骤（结构化干货）
[第三层] 每点展开（配案例/数据/操作细节）
[第四层] 汇总记忆点（帮观众总结带走）
[第五层] 结尾引导（收藏/关注）
```

---

## 各层详细说明

### 第一层：价值承诺（约30-60字）

**目的**：前15秒告诉观众"看完这条视频，你能得到什么"。

**格式**：
```
今天分享[N]个[关键词]，[受益人群]一定要看。
```

或：
```
[问题痛点]？今天给你一个清单，帮你[解决方案]。
```

**示例**：
> 去医院拿了一大袋检验报告，不知道哪几个数字最重要？今天给你5个必看指标，每一个都附上正常范围，记下来以后看报告就不慌了。

**⚠️ 注意**：价值承诺必须具体，禁止模糊表述。
BAD: `今天分享一些关于健康的知识`
GOOD: `今天分享5个中老年人体检必看的指标`

---

### 第二层：核心清单/步骤（结构骨架）

**目的**：让观众在进入细节前，先看到整体结构。

**格式**：
```
第一个/第一点：[关键词]
第二个/第二点：[关键词]
...
```

**⚠️ 注意**：
- 清单数量：3-7个为宜，超过7个需拆成两篇
- 每个关键词要足够短（3-8字），方便记忆
- 不要用"首先其次最后"（书面感太强），用"第一、第二..."或"第N个"

---

### 第三层：每点展开

每个清单项按以下结构展开：

```
[关键词] + [一句话说清楚是什么]
↓
[为什么重要 / 不注意会怎样]
↓
[具体操作 / 判断标准 / 数据范围]
↓
[口语化举例 / 创作者案例]
```

**每点展开字数**：80-150字/点

**示例（体检指标）**：
> 第一个，肌酐。说白了，这是测你肾功能好不好的。
> 肌酐升高，说明肾的过滤能力在下降。
> 正常范围：男性53-106，女性44-97，单位是μmol/L，你拿到报告对照一下就知道了。
> 我有个60多岁的患者，肌酐一直在115上下徘徊，但没有症状，结果两年后确诊慢性肾病2期。所以这个数字要定期追踪，不是看一次没问题就算了。

---

### 第四层：汇总记忆点（约80-120字）

**目的**：帮观众打包带走，强化"这条视频的价值"。

**格式**：
```
好，我们来快速回顾一下：
第一，[一句话总结]
第二，[一句话总结]
...
把这[N]个点记住，下次拿到报告/遇到这个情况，你就知道怎么处理了。
```

---

### 第五层：结尾引导（约30-50字）

**视频号版**（偏收藏利他）：
```
先收藏这条视频，需要的时候可以反复看。
如果你身边有需要的人，帮他们转一下。
```

**抖音版**（偏互动）：
```
你有哪个指标看不懂？评论区告诉我，我来解释。
先收藏，别到时候找不到。
```

## 字数分配参考

| 层次 | 视频号 | 抖音 |
|------|--------|------|
| 价值承诺 | 40-60字 | 30-50字 |
| 清单骨架 | 30-50字 | 20-40字 |
| 每点展开（×N点） | 100-150字/点 | 80-120字/点 |
| 汇总记忆点 | 80-120字 | 60-80字 |
| 结尾引导 | 30-50字 | 20-30字 |
| **总计（5点）** | **约700-1000字** | **约550-800字** |

---

## 收藏款常见错误

❌ 用"首先、其次、再次、最后"（书面套路感）
✅ 用"第一个、第二个..."或"来，第一点"

❌ 每个点只有概念没有数字/操作
✅ 每个点都有具体判断标准或操作步骤

❌ 汇总时重复展开部分的全部细节
✅ 汇总时每点只留一句话核心结论

❌ 清单超过7个没有分组
✅ 超过5个考虑加小标题分组（上篇/下篇、类型A/类型B）

❌ 没有口语感，像在念教材
✅ 每100字≥2个口语标记词

---

## 收藏款 vs 传播款 快速判断

| 问题 | 收藏款 | 传播款 |
|------|--------|--------|
| 看完第一反应 | "这个以后用得到" | "这个要转给人看" |
| 核心驱动力 | 实用/信息密度 | 情绪/共鸣/冲突 |
| 适合选题 | 方法论、指南、清单 | 热点、误区、故事 |
| 结构特点 | 列表/步骤 | 叙事/转折 |
| 生命周期 | 长（可反复看） | 短（热点型） |
