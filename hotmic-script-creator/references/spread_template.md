# 传播款脚本结构模板

传播款以情绪驱动为核心，目标是让观众看完第一句就想继续，看完全篇就想分享。

---

## 结构总览

```
[第一层] 前3秒钩子（打脸/反转/冲突）
[第二层] 问题放大（我为什么要关心这件事）
[第三层] 核心内容（创作者独家视角+事实支撑）
[第四层] 情绪升华（共情/呼吁/行动）
[第五层] 结尾引导（分享/评论/关注）
```

---

## 各层详细说明

### 第一层：前3秒钩子（约30-50字）

**目的**：在前3秒阻止用户划走。

**常见打法**：

**A. 打脸式**
```
你以为[常见认知]？错了。
[事实]。
```
示例：
> 你以为每天喝8杯水对身体好？错了。
> 对大多数中老年人来说，这个建议可能在伤肾。

**B. 反转式**
```
[令人意外的结论]，这不是标题党，听我说完。
```
示例：
> 医生私下都不怎么吃保健品，这不是标题党，听我说完。

**C. 共情式**
```
有多少人[痛点描述]？举手，我全是。
```
示例：
> 有多少人买了一堆保健品，结果家里老人根本吃不对？举手，我全是。

**D. 冲突式**
```
[强烈对比]。
```
示例：
> 花两万块打了外泌体，结果在医院查出了肿瘤标志物升高。

**⚠️ 注意**：打脸式开头不得使用反问句（创作者风格偏好），用陈述句+转折代替。
BAD: `你知道每天喝8杯水其实不对吗？`
GOOD: `每天喝8杯水，这个常识，对中老年人来说可能是错的。`

---

### 第二层：问题放大（约100-150字）

**目的**：让观众觉得"这件事和我/我的家人有关"。

**方法**：
- 引入具体场景（这种情况你可能见过/经历过）
- 点明危害或代价（不了解这件事的代价是...）
- 拉近与观众的关系（我门诊见过很多...）

**示例**：
> 我在门诊经常遇到这种情况：子女带着父母来，说"我妈/我爸最近总是腿肿"，一问，喝水喝得很多，因为听说这样好。结果反而加重了心脏的负担。
> 这不是个例，是一个很普遍的误区。

---

### 第三层：核心内容（约400-600字）

**目的**：交付实质性信息，建立创作者专业可信度。

**结构要求**：
- 逻辑线：为什么会这样 → 正确认知是什么 → 怎么做
- 每隔100字插入一个"口语标记词"，防止变成论文
- 至少一处"创作者独家视角"（来自采访回答）

**常见口语标记词**：
- 说白了、换句话说、你想想、说真的、问题是、关键在于、说到底

**示例段落**：
> 说白了，喝水这件事，和年龄是有关系的。年轻人肾功能好，多喝点排出去就行了。
> 但是年纪大了之后，肾的过滤能力下降，心脏的泵血功能也在下降。这时候如果喝水过多，水分排不出去，就会积在组织里，出现水肿，严重的会加重心衰。
> 我有个患者，78岁，之前每天严格喝8杯水，结果下午开始腿就肿起来了。来门诊一查，心功能已经有问题了。换句话说，他"按照书上说的做"，反而帮倒忙了。

---

### 第四层：情绪升华（约80-120字）

**目的**：把信息上升为"这件事的意义"，触发分享欲。

**视频号版**（偏温暖利他）：
> 老年人的身体和年轻人真的不一样，不能用同一套标准。
> 如果你的父母还在按照这些"通用建议"生活，帮他们核查一下，是很有必要的事。

**抖音版**（偏锋利直接）：
> 这些所谓的"健康建议"，适合年轻人，不适合60岁以上的人。
> 你以为在帮父母，可能在害父母。

---

### 第五层：结尾引导（约30-50字）

**视频号版**（侧重转发）：
```
如果你身边有中老年人，把这个视频转给他们，或者帮他们问问自己的医生。
关注[账号名]，我会持续分享这类实用的健康知识。
```

**抖音版**（侧重评论互动）：
```
你家里的老人还在喝"每天8杯水"吗？评论区告诉我，我看看有多少人中招了。
```

## 字数分配参考

| 层次 | 视频号 | 抖音 |
|------|--------|------|
| 前3秒钩子 | 30-50字 | 20-40字 |
| 问题放大 | 100-150字 | 60-100字 |
| 核心内容 | 500-600字 | 400-500字 |
| 情绪升华 | 80-120字 | 50-80字 |
| 结尾引导 | 30-50字 | 20-30字 |
| **总计** | **约800-1000字** | **约650-800字** |

---

## 传播款常见错误

❌ 开头就讲定义（"外泌体是一种..."）
✅ 先制造冲突，定义在中间解释

❌ 平铺直叙，没有情绪变化
✅ 情绪有起伏：开头紧张→中间峰回路转→结尾温暖/激烈

❌ 结尾说"感谢观看，关注我"
✅ 结尾有明确行动指令：转发/评论/帮家人看

❌ 每段都是书面句
✅ 每100字至少2个口语标记词
