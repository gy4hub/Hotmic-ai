# 指标计算方式和基准值参考手册

## 核心指标定义

### 互动率 (Engagement Rate)
```
互动率 = (点赞 + 评论 + 分享) / 播放量
```
- **优秀**: > 5%
- **良好**: 3-5%
- **平均**: 1-3%
- **较差**: < 1%

### 完播率 (Completion Rate)
```
完播率 = 完整观看次数 / 播放次数
```
- **优秀**: > 60%（视频 < 2分钟）
- **良好**: 40-60%
- **平均**: 25-40%
- **较差**: < 25%
- **注**: 视频越长，完播率基准越低

### 涨粉效率 (Follower Efficiency)
```
涨粉效率 = 新增粉丝数 / 播放量 × 10000
（即每万播放涨粉数）
```
- **优秀**: > 20人/万播
- **良好**: 10-20人/万播
- **平均**: 5-10人/万播

### 分享率 (Share Rate)
```
分享率 = 分享数 / 播放量
```
传播款内容的分享率基准: > 0.5%

## 内容类型基准值

### 传播款（热点/共鸣型）
| 指标 | 基准值 |
|------|--------|
| 播放量 | > 10万 |
| 完播率 | > 35% |
| 分享率 | > 0.7% |
| 涨粉效率 | 5-15人/万播 |

### 收藏款（干货/工具型）
| 指标 | 基准值 |
|------|--------|
| 播放量 | 3-20万 |
| 完播率 | > 45% |
| 收藏率 | > 3% |
| 涨粉效率 | 10-30人/万播 |

---

## 内容主线分析维度

三条内容主线（对应persona.json中的content_mix）各自有不同的ROI逻辑：
- **传播主线**：追求高播放量，分享率是核心指标
- **价值主线**：追求高涨粉效率，完播率和保存率是核心指标
- **商业主线**：追求转化，评论质量是核心指标

## 权重调整触发条件

| 条件 | 建议调整 |
|------|----------|
| 连续3条播放量 > 10万 | 该选题权重 +0.05 |
| 连续2条完播率 < 25% | 该选题权重 -0.03 |
| 分享率 > 1% | 内容策略权重 +0.03 |
| 涨粉效率 < 5/万播（连续3条） | 该内容线权重 -0.05 |
