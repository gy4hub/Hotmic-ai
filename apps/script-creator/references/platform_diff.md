# 视频号 vs 抖音 差异化规则

本文档定义了两个平台的脚本创作差异。
**核心原则**：相同内容，不同包装——同样的事实，针对不同平台语境优化呈现方式。

---

## 平台特性对比

| 维度 | 视频号 | 抖音 |
|------|--------|------|
| 主要用户群 | 35岁+，家庭决策者，高净值用户 | 全年龄，娱乐驱动，年轻用户多 |
| 平均停留时间 | 较长，用户习惯看完 | 较短，前3秒决定去留 |
| 转发逻辑 | "这个对家人有用" | "这个说得对/好笑/炸裂" |
| 评论文化 | 理性讨论，分享经历 | 站队、辩论、互怼 |
| 内容节奏 | 可以有铺垫，节奏稳 | 必须快，不能有废话 |
| 语气偏好 | 温暖、有人情味 | 直接、锋利、有态度 |
| 最佳时长 | 2-3分钟（800-1000字口播） | 1-2分钟（650-800字口播） |

---

## 视频号规范

### 开头策略
- **允许**2-3句铺垫，慢热型开头也可以接受
- 优先建立"信任感"：先让观众觉得你懂他
- 可以从"一个常见现象"切入，不一定要制造冲突

**示例开头**：
> 我在门诊接诊了很多中老年患者，有一个问题被问了很多次，今天统一来说一下。
> 很多家里有老人的朋友，都会遇到这样的情况：[问题描述]

### 语气标准
- 基调：知心的晚辈/靠谱的朋友/值得信任的专业人士
- 像"在餐桌上认真跟长辈解释一件事"
- 可以有感情词：确实、其实、我理解...
- 禁止过于戏剧化的情绪（炸裂/震惊等）

**语气词参考**：
- "其实啊"、"我理解这种担心"、"说实话"、"这确实是个常见误区"
- "家里有老人的注意一下"、"帮父母记住这一点"

### 篇幅控制
- 目标：**1000字以内**（约2-3分钟视频）
- 可接受：800-1000字
- 超过1000字：必须删减，优先删铺垫和重复论证

### 标题规范
- 长度：20-28字最佳
- 风格：信息型、利他型
- 避免：感叹号堆砌、过于煽情
- 优先包含：目标受众（"中老年人""父母"）+ 实用信息点

**视频号标题示例**：
```
✅ 父母每天喝8杯水？医生说这个习惯对老年人可能有害
✅ 拿到体检报告不会看？这5个指标最关键，帮父母记住
✅ 家里老人吃了一堆保健品，营养师告诉你哪些真的没必要
```

### 简介规范
- 长度：100-200字（含hashtag）
- 风格：**偏利他感**——强调"这对你/你的家人有什么用"
- 结构：核心内容提炼（1-2句）+ 观看提示（1句）+ hashtag

**示例简介**：
```
中老年人喝水的量和方式，不能直接套用年轻人的标准。
心功能不好的老人过多喝水，反而可能加重心脏负担。
帮父母收藏这条视频，或者一起看。
#中老年健康 #健康科普 #老年人喝水
```

### 首评规范
- 风格：理性平衡，补充信息
- 作用：提供更多细节、邀请理性讨论、汇总常见问题

**示例首评**：
```
补充几点：
1. 喝水量因人而异，心功能、肾功能、体重都会影响合适的量
2. 如果老人腿部有水肿，请先就医排查原因，不要自行减少用药
3. 有问题欢迎在评论区提，我会尽量回复
```

### 封面规范
- 主标题（大字）：6-10字，核心结论
- 副标题（小字）：补充说明，10-20字
- 风格：干净、专业、有信任感

## 抖音规范

### 开头策略（前3秒规则）
- **必须**：前3秒制造冲突、反转或强烈结论
- 禁止：任何铺垫、背景介绍、自我介绍
- 前15字：必须让观众产生"为什么？"或"真的吗？"

**抖音开头公式**：
```
[出乎意料的结论/冲突] + [一句话解释为什么要继续听]
```

**示例**：
> 医生自己不喝这类保健品。因为他们知道哪些是真有用，哪些是在交智商税。
> 今天讲3个你可能每天都在用的东西，但医生私下根本不推荐。

### 语气标准
- 基调：直接、有态度、轻微锋利
- 像"跟同龄好友吐槽一件事"
- 可以有轻微吐槽感，但不能攻击性太强
- 避免"感谢观看""下期见"等视频号礼貌结尾

**语气词参考**：
- "说真的"、"说白了"、"这很重要"、"不是吓你"、"我是认真的"

### 篇幅控制
- 目标：**视频号版的80-85%**
- 操作：删除所有铺垫句、合并重复论证、压缩案例细节
- 保留：核心结论 + 最有力的1-2个论据

### 删减优先级（从视频号版改抖音版时）
1. 先删：开头铺垫段（2-3句背景介绍）
2. 再删：案例中的细节描述（保留结论，删除过程）
3. 再删：重复强调的转折句（每个论点只保留一次）
4. 最后检查：每句话是否都在推进信息，没有停滞感

### 标题规范
- 长度：20-30字（抖音算法对长标题更友好）
- 风格：冲突型、情绪型、信息密度高
- 可以有感叹号（1-2个，不堆砌）
- 优先包含：冲突词（"错了""危险""没用""别再"）

**抖音标题示例**：
```
✅ 每天喝8杯水？对中老年人来说这可能是错的！
✅ 医生私下不吃的保健品，很多人每天都在买
✅ 体检报告拿到不看这5个数字，等于白体检
```

### 简介规范
- 长度：80-150字（含hashtag）
- 风格：**偏信息密度**——用最少的字传递最多的信息
- 结构：核心结论（1句）+ 视频重点列举（2-3点）+ hashtag

**示例简介**：
```
中老年人饮水量不能套用"每天8杯水"的通用建议。
本视频：①为什么老年人不能多喝水 ②哪类老人需要限水 ③正确的判断方法
#健康科普 #老年人健康 #医生说
```

### 首评规范
- 风格：锋利直接，推动讨论
- 作用：引发评论区站队、补充一个"意外信息点"

**示例首评**：
```
说个你可能不知道的：心脏科医生在门诊，经常需要劝老年患者少喝水。
你身边有没有这种情况？评论区说说。
```

### 封面规范
- 主标题（大字）：6-8字，带冲击力
- 副标题（小字）：补充说明，8-15字
- 风格：视觉冲击感强，文字对比明显

## 快速差异化检查清单

从视频号版改抖音版时，逐条检查：

- [ ] 前3秒是否够锋利（没有铺垫）
- [ ] 总字数是否压缩了15-20%
- [ ] 删掉了所有"感谢观看""帮家人转一下"等视频号结尾
- [ ] 结尾改成了"评论区告诉我"或站队引导
- [ ] 语气检查：有没有过于温和的表达（可以更直接）
- [ ] 标题是否重新写了（不是视频号标题的复制）
- [ ] 简介是否重新写了（不是视频号简介的缩减）
- [ ] 首评是否改成了引发讨论的锋利版本
